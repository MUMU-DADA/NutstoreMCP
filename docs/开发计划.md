## 继续不开放（已查清并否决）

| 能力 | 原因 |
|---|---|
| 任意路径 / 已有非空目录里创建文件 | 大小写别名会触发客户端冲突改名，改名分支可能移动或删除既有对象；结构安全依赖「本次新建空目录」 |
| 空文件创建 | 客户端走另一套元数据分支，未验证 |
| 删除对象 / 删除沙箱 / 解绑 / 迁移同步根 | 不可逆或影响用户数据 |
| C4 修改文件元数据 | 可将新版本指向任意内容引用，误用等于覆盖已有版本 |
| C5 恢复历史版本 | 可能写目标，冲突/权限继承未验证；只保留隔离实验选项 |
| 分享/ACL 写、文件锁、快捷方式、团队文件 | 无法撤销、绕过 GUI 校验或价值不足 |
| 修改客户端设置白名单之外 | 不开放 |

L1 WebDAV / L2 本地只读独立服务器已于 2026-10-18 按用户决定退役（需要额外应用密码，与插件路线冲突），代码、发布脚本和相关测试已删除。历史背景见 [归档索引](archive/README.md)。

## 可选后续

1. **F1 文件锁**：若确需，只对本次新建文件、用 F1 解锁（禁用 F2）、失败即停。
2. **C5 恢复/复制**：只做同沙箱、随机源 + 全新目标、单次调用。
3. **大文件扩展**：评估把 16 MiB 上限提高、接入 DEFLATE 压缩分支。
4. **事件保留期**：需等最早事件过期才能确定；当前已知下限 ≥ 9 天。
5. **L2 类本地只读能力**（同步状态/错误）如需恢复，应作为插件新工具在默认域实现，不走 WebDAV。

## 维护与交接

- 测试沙箱：`mcp-test`（ID/magic 运行期从 `nutstore_l3_sync_folders` 取，仓库只写 `<sandbox-id>`/`<magic>` 占位符）。
- 部署：日常改插件跑 `.\deploy\build.ps1`（热重载）；改钩子/契约跑 `.\deploy\restart-client.ps1`（可能需要 UAC）；首次安装见 [deploy/README.md](../deploy/README.md)。
- 写入调试：创建 `%LOCALAPPDATA%\NutstoreMcp\l3-write.enabled`（内容 `yes`），调试完删除；本地文件创建另需 `read-roots.txt`。
- 测试产物保留：不因「是测试文件」自动获得删除授权；删除能力本身不开放。
- 文档规则：工具增删/参数变化必须同步 [MCP-API](MCP-API.md)；过期文档移到 `docs/archive/` 并在归档索引登记；当前文档保持简洁，不堆历史细节。
