# NutstoreMCP 开发计划与完成情况

> `[x]` 已实现且端到端验证；`[~]` 正在实现或尚未完成验证；`[ ]` 未开始；`[-]` 决定不做。
>
> 最后更新：2026-10-09。写操作实测证据见 [调试验证记录](调试验证记录.md)。

## 一、总体目标

把坚果云桌面客户端只能在 GUI 上操作的能力做成 MCP 工具。

1. **绝不导致数据丢失。** 写操作必须有多重守卫，破坏性操作宁可不做。
2. **只用客户端自己的实现。** 不引入需要第三方凭据的接口，如 WebDAV 应用密码。
3. **修改实验只用新建目录和文件。** 原有云端和本地数据不作为写操作靶子。

## 四、安全机制

### 4.1 写入守卫

- [x] 解锁令牌 + `confirm=true` + `dryRun` 默认 `true`。
- [x] 令牌内容必须为 `yes`，空文件不解锁；测试结束移除本次创建的令牌。
- [x] 绑定拒绝非空目录、已有绑定、嵌套同步根和无法确认的状态。
- [x] 下载用 `FileMode.CreateNew`，已有本地目标拒绝覆盖。
- [x] 移动/建目录确认真实沙箱 ID、magic、本地绝对绑定路径；规范云端路径、父目录和目标冲突由真实读取核对。
- [x] 普通文件移动在默认域提交前再次核对源版本、大小和哈希；拒绝目录和已有目标，含大小写别名。
- [x] 默认域与插件双重写后复查。`attempted` 表示已尝试调用；只有两侧确认真实结果时 `executed=true`。
- [x] 失败也只读复查，不自动重试、不自动回滚，不删除冲突目标。

普通写入用 `l3-write.enabled`；系统级设置额外需要 `l3-write-system.enabled`，避免普通设置解锁连带允许安装驱动等操作。

### 4.2 禁止调用与真实状态

- [x] 插件与桥共用 **18 条** 禁止方法。包括解绑、同步根注销、删除对象、删除沙箱、`MakeDeleteSandboxRequest` 和四个可任意读写私有成员的反射 helper。
- [x] 桥在构造和调用前检查反射/委托签名与参数、返回值及数组/泛型容器；不执行未知枚举器或 getter 做扫描。
- [x] 禁止清单明确加入混淆删除哈希，不能只匹配语义名字。
- [x] `ClientCallSites` 登记调用点、状态副作用和安全依据；“远端读取”不等于“客户端不写状态”。
- [x] 设置写后读回；未落盘、钩子版本不匹配、结果无法确认均明确报告。

## 六、桥、部署与遗留事项

### 6.1 先桥验证，再固化，合并重启

用户指定流程：先用 `nutstore_bridge` 在新靶子验证语义，再固化有类型的专用接口，多个钩子变更合并一次重启。桥只允许客户端程序集，并阻止禁止方法；它不能替代每项写能力的专用守卫。

上传实验使用受限 `BUFFER|base64` 构造总量不超过 8 MiB 的只读流，脚本结束仅释放桥自有流；`VALUE|CreateFileParam|字段|参数...` 只构建新 boxed 结构体，七个字段白名单、精确类型、禁止静态/私有/readonly 字段。没有通用 SET。客户端调用异常不导出原始消息，仅保留类型及已登记的错误码/HTTP 状态。

已固化 A1–A10、B1、C1、C2、E4（A5/A6 合并）。默认域程序集不能卸载，改钩子必须重启；插件侧可热重载。稳定通用分发器仍是权衡项，**不自动列为后续目标**。

### 6.2 L1 WebDAV 去留

`src/NutstoreMcp` 独立服务器已实现 15 个工具和 90+ 测试，但需要 WebDAV 凭据，价值与项目当前方向不一致。**退掉 L1 仍待用户决定，保留现有代码和测试。**

### 6.3 测试目录

`mcp-test` 已有专门新建的测试对象，不再是空沙箱。当前绑定根 `%USERPROFILE%\Nutstore\1\mcp-test` 只用于已有绑定内的新靶子；**不要在客户端管辖的 `Nutstore\1` 树下再新建绑定目标**，此前发生过客户端清理目录。

外部本地靶子和下载目标使用 `%USERPROFILE%\NutstoreTest\*`。测试产物保留，删除能力仍禁止，不因“测试文件”自动获得删除授权。
