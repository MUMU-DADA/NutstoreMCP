# NutstoreMCP

把坚果云桌面客户端的查询和管理能力做成 MCP 插件。插件使用客户端已登录的会话和自己的实现，不需要申请第三方应用密码。

## 使用

已安装桥时，日常更新插件：

```powershell
.\deploy\build.ps1
```

插件可热重载；默认域钩子或跨域契约改变时，完成离线验证后合并一次安装和重启：

```powershell
.\verify.ps1
.\deploy\restart-client.ps1
```

首次安装、卸载和故障恢复见 [部署说明](deploy/README.md)。MCP 端点为 `http://127.0.0.1:17321/mcp`，只监听本机。

```yaml
transport: streamable-http
url: http://127.0.0.1:17321/mcp
```

客户端设置页的原生开关控制插件启停。插件运行在独立 AppDomain，客户端服务和 WPF 操作通过默认域钩子调用。

## 能力

| 类别 | 能力 |
|---|---|
| 查询 | 同步文件夹、云端目录、账号信息、流量用量、对象详情、版本历史、分享状态、联系人、事件游标、路径权限 |
| 管理 | 新建云端同步文件夹、绑定到本地空目录、修改白名单设置 |
| 文件 | 下载到不存在的本地目标、同沙箱普通文件移动/重命名、创建单层云端目录 |
| 诊断 | 插件状态、程序集与类型反射、通用开发桥 |

云端搜索是付费功能；免费账号会收到明确的服务端限制提示。最新完成状态、验证证据和后续工作见 [开发计划](docs/开发计划.md)与[交接说明](docs/交接说明.md)。

## 写入边界

专用写工具使用三重守卫：`l3-write.enabled` 内容为 `yes`、`confirm=true`、`dryRun=false`；默认只预演。令牌路径为 `%LOCALAPPDATA%\NutstoreMcp\l3-write.enabled`，调试完删除本轮令牌恢复锁定。系统级设置额外需要 `l3-write-system.enabled`。

移动仅允许普通文件、同一真实绑定沙箱、非根规范路径、父目录已存在。已有目标与大小写碰撞均拒绝；执行前后查询真实状态并比较大小和哈希。建目录不递归创建父目录，不覆盖已有对象。`attempted` 表示调用已尝试，`executed` 只在客户端返回成功且复查通过时为真；失败和结果未知都不自动重试或回滚。

修改操作只在新建测试目录和新文件上调试，用户原有对象只读。删除对象、删除沙箱、解绑和迁移同步根不暴露；危险哈希及语义入口也在桥层拒绝。

通用桥是开发入口，脚本可能修改状态，不能当只读工具。客户端方法名的语义必须由实现和调用链证明，不能由返回类型推断：一个看似“状态查询”的 bool 方法实际上会删除整个沙箱。

## 开发与验证

```powershell
.\verify.ps1
```

统一入口运行解决方案编译、主测试套件、net48 WPF/安全探针及部署配置补丁测试。主测试使用 xunit v3 与 Microsoft.Testing.Platform；安全组件用可变云端模型验证失败、并发变化和真实状态，不接触用户数据。在线验证必须另外走真实客户端 MCP。

混淆符号和数值契约集中在 [客户端绑定登记](src/NutstoreMcp.ClientBindings/README.md)。新增调用同时更新 `ClientSymbols` 和 `ClientCallSites`；版本升级先运行 `.\deploy\check-client-bindings.ps1`，只读比较完整签名、枚举、方法体和程序集指纹。部署前会自动执行这一检查，差异必须复核后再记录新基线。统一验证也包含登记检查和检查器离线自测。

通用桥对每个调用接收者、方法声明和属性/字段声明检查程序集，拒绝反射、委托和插件自身类型，危险入口共用同一份清单。不读取数据库中的会话凭据，不写客户端真实数据库来模拟业务操作。

## 独立服务器

仓库保留 `src/NutstoreMcp` 的 L1 WebDAV 和 L2 本地只读服务器及测试，它们是早期独立方案，不是插件使用的前提。L1 需要应用密码、云端与本机路径白名单、默认只读；其去留仍待决定，本轮不删除既有实现。

```powershell
dotnet run --project src/NutstoreMcp -- --doctor
.\publish.ps1
```

自包含发布保留 exe 与 `e_sqlite3.dll` 两文件；不要启用 `IncludeNativeLibrariesForSelfExtract`，受限临时目录会造成启动失败。
